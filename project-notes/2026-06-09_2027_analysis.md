# Results analysis — the self-play "gains" are format compliance, not reasoning

**Date:** 2026-06-09 20:27
**Branch:** `simplify-single-integer-no-python`
**Scope:** Re-analysis of all local GSM-hard eval sweeps. This is the new anchor finding — read before re-litigating DPO vs GRPO or verifiability.

---

## TL;DR

The headline "~20% self-play return" is **real on graded pass@1/pass@k but is driven entirely by the model learning to emit the `FINAL_ANSWER:` format**, not by improved math. Eval scores with a **strict `FINAL_ANSWER:` parser** (`grpo_math/eval/eval_gsm8k.py:106`, `grpo_math/data/reward.py:42`), so teaching the model to emit the tag (format_rate 0.44 → 0.99) lets the parser score answers it could already produce. **Conditional accuracy (correct | parseable) is flat-to-declining.** Pushing training past format saturation **degrades reasoning**.

Verifiability / judge design is **not** the bottleneck and is currently confounded out of every downstream number.

---

## Evidence

Three remote GSM-hard sweeps, all vs the same base (150 samples, k=4). Decompose pass@1 into the **format channel** (`format_rate`) and the **reasoning channel** (`condAcc@1 = pass@1 / format_rate`).

### Run A — solver self-play (the one the user pasted)

```
cycle  pass@1  format   condAcc@1
base    20.0    42.2     47.4    <- baseline reasoning
c012    20.0    56.0     35.7
c014    24.0    72.0     33.3
c018    28.0    89.3     31.4
c020    33.3    91.7     36.3    <- peak pass@1
c021    30.7    94.5     32.5
c022    23.3    97.5     23.9
c023    16.0    97.8     16.4
c024    16.0    96.7     16.5
c025    20.7    97.8     21.2    <- format maxed, pass@1 back at base
```

- pass@1 rise tracks format_rate exactly (42% -> 98%).
- condAcc **declines 47 -> 32 -> 16**: reasoning actively corrupted while format improves.
- Once format saturates (~c22) the mask is gone and pass@1 collapses to baseline, now with peak format + minimum reasoning. Classic over-optimization on a format-correlated signal.

### Run B — `continue_sweep` (`outputs/evals/gsmhard_remote/continue_sweep_150_summary.json`)

- format_rate 0.44 -> 0.99; pass@1 0.20 -> 0.36-0.45.
- condAcc **flat ~0.40-0.45** (base 0.455; best cycle036 0.452). Best case = "base reasoning + perfect formatting." No reasoning gain.

### Run C — `judgefull_gated_remaining_completed` (`outputs/evals/gsmhard/.../summary.json`)

- format_rate **stuck ~0.40-0.44 every cycle** -> pass@1 flat/down.
- Only the lenient `contains_correct` metric inflated (+0.20). That metric is a substring match of the gold integer (leaks via verbosity) — distrust it. `both_first_formatted` shows base MORE accurate than the trained model.

### Cross-check: "non-strict" pass@1 does NOT control for format

Across all 40 cycle rows, `pass_at_1 - strict_pass_at_1` is **min 0.000, max 0.020, mean 0.007**. The non-strict extractor (`reward.py:25`) only adds a "last integer in text" fallback when the `FINAL_ANSWER:` tag is absent (line 36); empirically that fallback rescues <=2pp because on multi-step problems the last integer is an intermediate value. So strict and non-strict both gate on the tag and rise/fall together — neither isolates reasoning.

---

## What this means

1. **Format is a confound, not a result.** Every downstream pass@1 delta so far is a format delta.
2. **The loop, run long, is net-harmful to reasoning** (condAcc 47 -> 16 in Run A).
3. **Verifiability/judge/question-reward design is untestable from these numbers** until format is held constant.

## Caveat on rigor

`condAcc@1 = pass@1 / format_rate` is an **approximation** (pass@1 is first-completion-only; format_rate is over all k). Direction is robust (stable across format 0.44 -> 0.99), but confirm with an **exact** P(correct | parseable) from raw per-completion JSONL on the server. The eval scripts that produced these summaries live on the server, not locally (the git status snapshot listing them was stale).

---

## Next actions

1. **Pull raw eval completions from the server** (washu-lab) to compute exact conditional accuracy and inspect what late-cycle (degraded) completions look like.
2. **Remove the format confound**: SFT base to ~100% `FINAL_ANSWER:` emission, *then* run self-play — only then is a pass@1 delta a real reasoning delta.
3. **Track condAcc (or an intent-aware answer extractor)** as the primary metric, never raw pass@1.
4. **Add early-stop / KL anchoring**: degradation is monotonic with cycles; useful window in Run A was ~c14-20.
